### Regola fondamentale: pre-calcolo fuori da setPlayer
Tutto ciò che serve per **notifiche** (setTimeout fuori da setPlayer) DEVE essere calcolato prima della chiamata a `setPlayer`. I riferimenti a variabili dichiarate dentro `setPlayer(p=>{...})` sono inaccessibili dal codice esterno.

```js
// PATTERN CORRETTO:
const _valoreEsterno = calcola_da_player_closure();
setPlayer(p => {
  // usa _valoreEsterno qui
  return { ...p, ... };
});
setTimeout(() => {
  notify(_valoreEsterno); // ✅ accessibile
}, 200);
```
